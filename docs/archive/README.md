# Archive

Superseded documents, kept as a historical record. **Nothing here is
maintained, and nothing here should be treated as current.**

These files are deliberately left exactly as they were written. They describe
the project as it was specified at the time, not as it is now — so they still
use old names, paths, and product framing. That is the point: rewriting them
would destroy the record of what was actually asked for.

For current documentation see [`../owner-guide.md`](../owner-guide.md) (how to
operate the system) and [`../HANDOFF.md`](../HANDOFF.md) (state and remaining
launch steps).
